知识摄入全流程 ★ 时序图 .claude/skills/ingest

覆盖 participant / autonumber / Note / alt / loop / activate 六种时序图元素

sequenceDiagram
    autonumber
    participant U as 👤 用户
    participant A as 🤖 ingest
    participant R as 📥 raw/
    participant W as 🧠 wiki/
    participant S as 💾 state.json

    Note over U,S: 阶段一 · 增量检测

    U->>A: /ingest raw/01-articles
    A->>S: 读取处理记录
    S-->>A: 返回已完成哈希
    A->>A: 比对文件哈希

    alt 文件未处理
        Note over A,W: 阶段二 · 知识编译
        A->>R: 读取源文件
        R-->>A: 返回正文
        A->>U: 展示提取的实体与概念
        U-->>A: 确认 / 修正
        activate A
        A->>W: 创建来源摘要 (sources/)
        A->>W: 创建或更新概念页
        A->>W: 创建或更新实体页
        deactivate A
        loop 每个提取出的概念
            A->>W: 增量合并 [[双链]]
        end
    else 已处理过
        A-->>U: 跳过（内容无变更）
    end

    A->>S: 写入处理状态
    A->>R: 归档至 raw/09-archive/
    A-->>U: ✅ 输出编译完成报告

知识对象模型 classDiagram

类图：类名条实心强调，属性区与分隔线统一描边

classDiagram
    class WikiPage {
        +String title
        +String type
        +List tags
        +List sources
        +Date last_updated
        +Date last_refreshed
        +render()
        +validate() bool
    }

    class Concept {
        +String definition
        +String complexity
        +List related
        +merge(Concept) void
    }

    class Entity {
        +String entity_type
        +List relations
        +updateProfile() void
    }

    class Source {
        +String source_type
        +String credibility
        +String archive_url
        +summarize() String
    }

    class Synthesis {
        +String question
        +List evidence
        +String confidence
        +conclude() String
    }

    class MOC {
        +String domain
        +query() List
    }

    WikiPage <|-- Concept
    WikiPage <|-- Entity
    WikiPage <|-- Source
    WikiPage <|-- Synthesis
    Concept "*" --> "*" Entity : 关联
    Source "1" --> "*" Concept : 提炼
    Synthesis --> Source : 引用
    MOC o-- WikiPage : 聚合

页面生命周期状态机 stateDiagram-v2

状态图：起止节点用蓝实心，复合状态用虚线分组框

stateDiagram-v2
    [*] --> Draft : 新建

    state "草稿" as Draft
    state "审阅中" as Review
    state "已发布" as Published
    state "待刷新" as Stale

    Draft --> Review : 内容完整
    Review --> Draft : 退回修改
    Review --> Published : 通过校验

    state Published {
        [*] --> Active
        Active --> Archived : 被取代
        Archived --> [*]
    }

    Published --> Stale : 超过刷新周期
    Stale --> Published : refresh 完成
    Stale --> Review : 发现冲突
    Published --> [*] : 废弃
