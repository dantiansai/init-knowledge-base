样式指南 · Editorial

编辑风的定位是中文出版物的版面感：标题走衬线承担「版面」职责，正文走黑体保证屏幕可读性；表格只留横线，引用去底色只留竖线；界面用发丝线分区，用一道 2px 强调色短线标记当前位置。

一、色彩系统

明色为「宣纸」，暗色为「夜墨」。强调色取胭脂，语义色全部压到出版级低饱和。

二、排版层级

这是 H3（黑体，1.2em）

正文 16px，行高 1.8，字距 +0.012em —— 中文长文在这个组合下最省力。栏宽 42rem（约 34 个汉字/行），是屏幕阅读的舒适上限。

加粗用 650 字重而不是 700，避免中文字面糊成一团。斜体走真斜体，行内代码走等宽 + 浅底。关键词高亮：被标记的句子会垫一层蜂蜜金。

这是 H4（1.06em，黑体）

这是 H5（0.97em，压暗）
这是 H6（0.88em，字距拉开，最淡）

层级靠字体族和线来区分，不靠大小硬撑：H1 带一道短胭脂线 → H2 带上方发丝线（像印刷品的分栏线）→ H3 起转为黑体。

三、列表与任务

无序列表（圆点压到最淡，缩进参考线几乎看不见）：

  • 第一层，圆点压到最淡
    • 第二层
  • 回到第一层

有序列表（编号用衬线 + 胭脂色，是版面里少数允许「出声」的地方）：

  1. 界定研究问题
  2. 收集来源并评估可信度
  3. 交叉验证，标记冲突

任务列表（复选框是 2px 圆角的方块，不是圆点）：

  • 已完成的条目会压暗并划掉
  • 未完成条目保持常态

四、表格（三线表）

维度旧样式编辑风收益
边框全网格线只有三条横线视觉噪音↓
表头灰底 + 蓝字无底 + 1.5px 主分隔线像出版物
行分隔1px 灰线1px 发丝线依然可读
第一列与正文同加重为行标题扫读更快

数字列用 <td align="right"> 会自动启用等宽数字对齐（上表最后一列）。

五、全部 Callout 类型

✎ 笔记 / note / info

墨蓝。左侧 2px 实色竖线 + 一圈发丝描边，底色只留 4.5% 透明度。

▤ 摘要 / abstract

青。适合放在页面顶部的「一句话总结」。

☑ 待办 / todo

青。与摘要同色系。

✦ 提示 / tip / important

琥珀。适合放「此处的坑」。

✓ 成功 / success / done

苔绿。

? 问题 / question / faq

紫檀。

⚠ 警告 / warning / caution

赭石。

✕ 危险 / danger / error

朱。

◈ 示例 / example

紫檀。

❝ 引用 / quote / cite

这个变体会自动切换到衬线字体，当引文用。

折叠式（标题末尾加 - 默认折叠，箭头会旋转，展开高度不跳动）：

? 点开看答案 ▾

折叠状态的箭头会旋转，展开高度不跳动。

六、版式扩展示例

6.1 多栏

✎ 左栏

子块按可用宽度自动等分，放不下就换行。

⚠ 中栏

指定栏数用 |2col、3col、4col。

✓ 右栏

窄屏（< 640px）自动退回单栏。

6.2 浮动批注框

ℹ 右侧浮动

这段文字会被放在正文右侧，正文自动绕排。窄屏下自动取消浮动，回到正常流。

尺寸可选 small / medium / large，方向可选 left / right。

正文继续推进，观察右侧的批注框如何与段落并行排布。这是报纸与学术出版物里常见的排版手法，让补充信息不打断主线阅读节奏。

6.3 页边注

▏ 边注

Tufte 式页边批注：只留一条顶线，字号 0.82em，适合放「补充说明」「我的怀疑」这类不影响主线的信息。

6.4 图片画廊

▦ 画廊（等高等宽裁切网格）

> [!note|gallery] 内的图片会自动排成等高裁切网格。

def compile_to_wiki(raw_path: Path, wiki_root: Path) -> list[str]:
    """把 raw/ 下的资料编译进 wiki/ 并回写双链"""
    pages: list[str] = []

        page = render_page(doc)

十一、图表配色

Mermaid / Markmap / Canvas 的配色由 07-diagrams.css 统一接管，源码里只写语义 class，不写色值：

flowchart LR
    A["原始资料"] --> B["ingest 编译"]
    B --> C["wiki 知识库"]

    class A blue
    class B green
    class C cyan

可用语义 class：blue cyan green yellow orange red purple，以及实心强调用的 solid。

✕ 两条禁令

不要写 classDef xxx fill:var(--x) 或 fill:rgba(...) —— Mermaid 的 classDef 只接受简单色值，写变量或 rgba 会直接抛解析错误，整张图渲染失败。

也不要写 style 节点 fill:#hex —— 那样绕过了主题变量，暗色模式下必然失配。
